# Rebuilt 2026

The code for 2826 Wave Robotics' 2025 Rebuilt robot.

[Chief Delphi Open Alliance Thread](https://www.chiefdelphi.com/t/frc-2826-wave-robotics-2026-open-alliance-build-thread/508460/19)

Features (probably):
- Triple coaxial turret
- Automatic passing and scoring
- Reliable full-field localization using PhotonVision
- Advanced logging with AdvantageKit
- Full field simulation with maple-sim
- Autonomous vision-based piece acquisition using a custom AI model
